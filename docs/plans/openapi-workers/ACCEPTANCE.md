| B-09 | 缓存与冷编译 | 份数/累计字节限制、并发去重、活跃引用保护；慢/失败编译不无限消耗或阻塞热调用 | 01/05 |
| B-10 | 凭证与审计 | 自定义认证 Header 脱敏，产物不包含合成 token 原文；缓存/共享客户端无用户认证状态 | 01/02/04/05 |

## 证据格式

每份结果至少包含：场景 ID、verified/partial/blocked、命令或请求、测试拓扑、开始/结束时间、预期与实际结果、非敏感产物路径、未验证项。

共享协议样例不含凭证。假业务系统使用运行时合成值，测试证据记录主体标签和断言结果，不保存 token 原文。吞吐和内存测量写明配置、负载和局限，不外推生产容量。
