title: "Explore Obot"
---

Start with [Connect to a vMCP](./connect.md) to use an existing endpoint, or [Create a vMCP](./govern.md) to assemble one from catalog servers. Then explore the other capabilities below.

| Your task | Start here | Who can help |
|---|---|---|
| Connect an AI client to approved tools | [Connect to a vMCP](./connect.md) | Your Obot administrator grants server access |
| Create and share an endpoint from catalog servers | [Create a vMCP](./govern.md) | An administrator creates shared vMCPs and profiles |
| Route model requests through Obot | [Connect LLM clients](../llm-gateway/connect-clients.md) | An administrator configures providers and model policies |
| Publish reusable skills | [Publish and distribute skills](../registries/publish-skills.md) | An administrator adds sources and access policies |
| Inventory and govern local AI tools | [Enroll devices](../device-management/enroll.md) | An administrator configures Obot Sentry |
| Install Obot | [Deployment options](../installation/overview.md) | An operator provides infrastructure and authentication |

:::note
Check [editions and feature availability](../enterprise/overview.md).
:::
