# Server configuration {#obot-configuration-reference}

The Obot server is configured with environment variables.

Each setting has its own heading, so you can link to it directly with the variable name in lowercase, for example `#obot_server_mcpaudit_log_retention_days`.

## General {#general}

### `OBOT_SERVER_HOSTNAME` {#obot_server_hostname}

Tell Obot what its server URL is so that things like OAuth, LLM proxying, and invoke URLs are handled correctly.

**Default:** not set

### `OBOT_SERVER_DSN` {#obot_server_dsn}

Obot uses a database backend. By default, it will use a sqlite3 local database when running the plain Obot binary. The Obot container will use an internal PostgreSQL database (not recommended for production). This environment variable allows you to specify another database option. For example, you can use a postgres database with something like `OBOT_SERVER_DSN=postgres://user:password@host/database`.

**Default:** not set

### `OBOT_SERVER_LICENSE_KEY` {#obot_server_license_key}

An Obot license key. It takes precedence over a key stored in the database, and the key can't be changed or removed in the UI while it's set. Obot validates it with `https://api.keygen.sh`; see [Editions and licensing](../enterprise/overview.md#how-obot-validates-a-license).

**Default:** not set

### `GITHUB_AUTH_TOKEN` {#github_auth_token}

Obot makes heavy use of repositories hosted on GitHub. Care is taken to cache these and only re-check when necessary. However, rate-limiting can happen. Setting a read-only token here can alleviate many of these issues. No grants are required for either a 'classic' or 'fine-grained' token to access public repos (read-only). If you want to give the token access to private repos, you will need to give it `repo` (for a 'classic' token) or `contents (read-only)` and `metadata (read-only)`.

**Default:** not set

### `OBOT_SERVER_GIT_MAX_REPO_SIZE_MB` {#obot_server_git_max_repo_size_mb}

Maximum repository size for git clones, in MB (1 MB = 1,048,576 bytes). Applies to GitHub/GitLab size pre-checks and cumulative bytes written during cloning. Must be a positive integer; invalid values prevent server startup. Also available as `--git-max-repo-size-mb`.

**Default:** `100`

### `NAH_THREADINESS` {#nah_threadiness}

Sets the number of concurrent threads that can run in the Obot controller.

**Default:** `10`

### `OBOT_SERVER_DISABLE_UPDATE_CHECK` {#obot_server_disable_update_check}

Disable the Obot server update check.

**Default:** `false`

### `OBOT_SERVER_PRODUCT_ANALYTICS_MODE` {#obot_server_product_analytics_mode}

[Product analytics](./product-analytics.md) mode: `consent` lets admins choose, `on` forces analytics on, and `off` disables analytics.

**Default:** `consent`

### `OBOT_SERVER_HIDE_K8S_DETAILS` {#obot_server_hide_k8s_details}

Hide Kubernetes configuration details such as the Server Scheduling page from the UI.

**Default:** `false`

## Authentication and rate limiting {#authentication}

### `OBOT_SERVER_ENABLE_AUTHENTICATION` {#obot_server_enable_authentication}

Enables authentication for Obot.

**Default:** `false`

### `OBOT_BOOTSTRAP_TOKEN` {#obot_bootstrap_token}

Sets a bootstrap token. If authentication is enabled, one will be autogenerated for you if this is not set.

**Default:** not set

### `OBOT_SERVER_LOCAL_AUTH_INITIAL_OWNER_EMAIL` {#obot_server_local_auth_initial_owner_email}

Provisions this email as the initial owner with the built-in Local provider. Must be set with `OBOT_SERVER_LOCAL_AUTH_INITIAL_OWNER_SETUP_TOKEN`. This disables bootstrap-token login.

**Default:** not set

### `OBOT_SERVER_LOCAL_AUTH_INITIAL_OWNER_SETUP_TOKEN` {#obot_server_local_auth_initial_owner_setup_token}

Randomly generated, high-entropy secret (at least 32 characters; for example, `openssl rand -hex 32`) bound to the initial owner setup link. Obot stores only its hash and revokes it when password setup completes.

**Default:** not set

### `OBOT_SERVER_LOCAL_AUTH_INITIAL_OWNER_SETUP_TOKEN_EXPIRATION_HOURS` {#obot_server_local_auth_initial_owner_setup_token_expiration_hours}

Number of hours the initial owner setup link remains valid.

**Default:** `168`

### `OBOT_SERVER_UNAUTHENTICATED_RATE_LIMIT` {#obot_server_unauthenticated_rate_limit}

Rate limit for unauthenticated requests (requests per second). Unauthenticated requests are tracked by source IP address.

**Default:** `100`

### `OBOT_SERVER_AUTHENTICATED_RATE_LIMIT` {#obot_server_authenticated_rate_limit}

Rate limit for authenticated non-admin requests (requests per second). Authenticated requests are tracked by user ID. Admin users are exempt from rate limiting.

**Default:** `200`

## Encryption {#encryption}

### `OBOT_SERVER_ENCRYPTION_PROVIDER` {#obot_server_encryption_provider}

Configures an encryption provider for credentials in Obot. One of `aws`, `gcp`, `azure`, `custom`, or `none`.

**Default:** `none`

### `OBOT_SERVER_ENCRYPTION_CONFIG_FILE` {#obot_server_encryption_config_file}

The path to a file containing the encryption configuration. Only used when `OBOT_SERVER_ENCRYPTION_PROVIDER` is `custom`.

**Default:** not set

### `OBOT_SERVER_ENCRYPTION_KEY` {#obot_server_encryption_key}

Sets the key to be used for encryption. Should only be set if `OBOT_SERVER_ENCRYPTION_PROVIDER` is `custom`.

**Default:** not set

## Database connection pools {#database-connection-pools}

### `KINM_DB_CONNECTIONS` {#kinm_db_connections}

Sets both the maximum open and idle connection counts in the Kinm database pool. `KINM_DB_MAX_CONNECTIONS` and `KINM_DB_MAX_IDLE_CONNECTIONS` override the corresponding values.

**Default:** `5`

### `KINM_DB_MAX_IDLE_CONNECTIONS` {#kinm_db_max_idle_connections}

The maximum number of idle connections in the Kinm database pool. Overrides the idle connection count set by `KINM_DB_CONNECTIONS`.

**Default:** `2`

### `KINM_DB_MAX_CONNECTIONS` {#kinm_db_max_connections}

The maximum number of open connections in the Kinm database pool. Overrides the open connection count set by `KINM_DB_CONNECTIONS`.

**Default:** `5`

### `KINM_DB_MAX_CONNECTION_LIFETIME_SECONDS` {#kinm_db_max_connection_lifetime_seconds}

The maximum lifetime of a connection in the Kinm database pool, in seconds.

**Default:** `180`

### `KINM_DB_WATCH_POLL_SECONDS` {#kinm_db_watch_poll_seconds}

How long a Kinm watch waits before listing again when nothing has woken it, in seconds. Only applies while the change listener is connected. Without a connected listener a watch polls every 2 seconds, which this does not change.

**Default:** `120`

### `KINM_DB_NOTIFY_DEBOUNCE_MILLISECONDS` {#kinm_db_notify_debounce_milliseconds}

How often change notifications may wake the watches on one table, in milliseconds. The first change after a quiet moment is never delayed.

**Default:** `1000`

### `KINM_DB_DISABLE_NOTIFY` {#kinm_db_disable_notify}

Disables Kinm's use of PostgreSQL LISTEN/NOTIFY, so replicas learn about each other's writes by polling every 2 seconds instead.

**Default:** `false`

### `OBOT_AUTH_PROVIDER_POSTGRES_MAX_IDLE_CONNECTIONS` {#obot_auth_provider_postgres_max_idle_connections}

The maximum number of idle connections in the PostgreSQL database pool used by authentication providers.

**Default:** `2`

### `OBOT_AUTH_PROVIDER_POSTGRES_MAX_CONNECTIONS` {#obot_auth_provider_postgres_max_connections}

The maximum number of open connections in the PostgreSQL database pool used by authentication providers.

**Default:** `5`

### `OBOT_AUTH_PROVIDER_POSTGRES_CONNECTION_LIFETIME_SECONDS` {#obot_auth_provider_postgres_connection_lifetime_seconds}

The maximum lifetime of a connection in the PostgreSQL database pool used by authentication providers, in seconds.

**Default:** `180`

## LLM gateway {#llm-gateway}

### `OPENAI_API_KEY` {#openai_api_key}

Configures the [LLM gateway](./model-providers.md#openai-and-anthropic-keys-at-startup)'s `openai` provider with this key at startup. If the value changes, Obot updates the provider's key on the next start. You can also add providers and keys under **LLM Gateway** → **Providers**.

**Default:** not set

### `ANTHROPIC_API_KEY` {#anthropic_api_key}

Configures the [LLM gateway](./model-providers.md#openai-and-anthropic-keys-at-startup)'s `anthropic` provider with this key at startup. If the value changes, Obot updates the provider's key on the next start.

**Default:** not set

### `OBOT_SERVER_DAILY_USER_INPUT_TOKEN_LIMIT` {#obot_server_daily_user_input_token_limit}

Daily input token limit per user in the LLM gateway's *Daily token limit* budget, which the gateway puts on every profile when it first starts. Administrators are exempt. It is used only then; after that, edit each profile's budget on the **Profiles** tab of the **LLM Gateway** page. Set to a negative value to leave out this limit.

**Default:** `10000000`

### `OBOT_SERVER_DAILY_USER_OUTPUT_TOKEN_LIMIT` {#obot_server_daily_user_output_token_limit}

Daily output token limit per user in the LLM gateway's *Daily token limit* budget, which the gateway puts on every profile when it first starts. Administrators are exempt. It is used only then. Set to a negative value to leave out this limit.

**Default:** `100000`

### `OBOT_SERVER_LLM_GATEWAY_DATA_DIR` {#obot_server_llm_gateway_data_dir}

Where the LLM gateway keeps model price and capability files.

**Default:** `$XDG_DATA_HOME/obot/llm-gateway`

### `OBOT_SERVER_LLM_GATEWAY_LOG_LEVEL` {#obot_server_llm_gateway_log_level}

Log level for the embedded LLM gateway (`debug`, `info`, `warn`, `error`).

**Default:** `warn`

### `OBOT_SERVER_LLM_GATEWAY_MODEL_DATA_URL` {#obot_server_llm_gateway_model_data_url}

Where the LLM gateway refreshes model prices and capabilities from, every 6 hours. Obot's published images and release binaries include a copy of this data; set `off` to use only that copy.

**Default:** `https://upgrade-server.obot.ai/v1/model-data`

### `OBOT_SERVER_MODEL_PROXY_URL` {#obot_server_model_proxy_url}

MCP Tester model proxy service base URL, used for generation only when the LLM gateway has no providers configured. An explicitly empty string disables generation. Custom URLs must use HTTPS; HTTP is allowed only with `OBOT_DEV_MODE=true`.

**Default:** `https://model-service.obot.ai`

## Audit logs and retention {#audit-logs-and-retention}

### `OBOT_SERVER_MCPAUDIT_LOG_RETENTION_DAYS` {#obot_server_mcpaudit_log_retention_days}

The number of days to retain MCP audit logs before they are automatically deleted. Set to `0` to disable automatic cleanup. Use the [audit log export](./audit-log-export.md) functionality to preserve logs beyond this period.

**Default:** `90`

### `OBOT_SERVER_LLMAUDIT_LOG_RETENTION_DAYS` {#obot_server_llmaudit_log_retention_days}

The number of days to retain LLM audit logs before they are automatically deleted. Set to `0` to disable automatic cleanup.

**Default:** `90`

### `OBOT_SERVER_DEVICE_SCAN_RETENTION_DAYS` {#obot_server_device_scan_retention_days}

The number of days to retain submitted device scans before they are automatically deleted. Set to `0` to disable automatic cleanup.

**Default:** `90`

### `OBOT_SERVER_EGRESS_AUDIT_LOG_RETENTION_DAYS` {#obot_server_egress_audit_log_retention_days}

**Experimental.** Controls how many days egress audit records are retained after their last update. Set to `0` to disable cleanup. In Helm, set this under `config.OBOT_SERVER_EGRESS_AUDIT_LOG_RETENTION_DAYS`.

The admin Audit Logs page includes a **Claude Environments** tab. Only members of the auditor group can read request/response bodies and headers, including administrators.

See [experimental Claude Environments](../claude-environments/overview.md) for setup, access control, and audit limitations.

**Default:** `90`

### `OBOT_SERVER_DISABLE_MCPAUDIT_LOG` {#obot_server_disable_mcpaudit_log}

Disables collection and persistence of new MCP audit logs, including MCP gateway traffic and tool calls reported by local agents on managed devices. Device submissions are still accepted, then discarded. Existing logs remain available.

**Default:** `false`

### `OBOT_SERVER_DISABLE_LLMAUDIT_LOG` {#obot_server_disable_llmaudit_log}

Disables collection and persistence of new LLM gateway audit logs. Existing logs remain available.

**Default:** `false`

### `OBOT_SERVER_MCPAUDIT_LOG_PERSIST_INTERVAL_SECONDS` {#obot_server_mcpaudit_log_persist_interval_seconds}

The interval in seconds at which buffered MCP audit logs are flushed to the database.

**Default:** `5`

### `OBOT_SERVER_MCPAUDIT_LOGS_PERSIST_BATCH_SIZE` {#obot_server_mcpaudit_logs_persist_batch_size}

The number of MCP audit log entries written to the database in a single batch.

**Default:** `1000`

### `OBOT_SERVER_AUDIT_LOGS_MODE` {#obot_server_audit_logs_mode}

Configures the storage backend for audit logs in Obot. Can be `off`, `disk`, or `s3`.

**Default:** `off`

### `OBOT_SERVER_AUDIT_LOGS_STORE_S3BUCKET` {#obot_server_audit_logs_store_s3bucket}

The name of the S3 bucket to store audit logs in.

**Default:** not set

### `OBOT_SERVER_AUDIT_LOGS_STORE_S3ENDPOINT` {#obot_server_audit_logs_store_s3endpoint}

If `OBOT_SERVER_AUDIT_LOGS_MODE` is `s3` and you are not using AWS S3, this needs to be set to the S3 api endpoint of your provider.

**Default:** not set

### `OBOT_SERVER_AUDIT_LOGS_STORE_USE_PATH_STYLE` {#obot_server_audit_logs_store_use_path_style}

Whether to use path-style addressing for S3 object names.

**Default:** not set

### `OBOT_SERVER_AUDIT_LOGS_COMPRESS_FILE` {#obot_server_audit_logs_compress_file}

Controls whether to compress audit log files.

**Default:** `true`

## MCP server runtime {#mcp-server-runtime}

### `OBOT_SERVER_MCPRUNTIME_BACKEND` {#obot_server_mcpruntime_backend}

The runtime backend to use for running MCP servers: docker or kubernetes.

**Default:** `kubernetes` in the helm chart, `docker` otherwise

### `OBOT_SERVER_MCPBASE_IMAGE` {#obot_server_mcpbase_image}

Base image for MCP servers in Kubernetes or Docker. Also used for Docker setup containers for wrapper configuration and file configuration across runtimes. Custom images must provide `sh`, `cp`, and `rm`, and support running setup as root.

**Default:** `ghcr.io/obot-platform/mcp-images/stdio-wrapper:v0.26.2`

### `OBOT_SERVER_MCPOPEN_APIIMAGE` {#obot_server_mcpopen_apiimage}

Container image used to host OpenAPI MCP servers with the Docker or Kubernetes runtime backend.

**Default:** `ghcr.io/obot-platform/mcp-images/openapi-mcp:v0.27.2`

### `OBOT_SERVER_MCPHTTPWEBHOOK_BASE_IMAGE` {#obot_server_mcphttpwebhook_base_image}

Deploy MCP HTTP webhook servers in the cluster using this base image.

**Default:** `ghcr.io/obot-platform/mcp-images/http-webhook-mcp-converter:v0.26.2`

### `OBOT_SERVER_MCPIMAGE_PULL_SECRETS` {#obot_server_mcpimage_pull_secrets}

Comma-separated Kubernetes secret names to use as static image pull secrets for every MCP server Deployment. When set, managed image pull secrets are disabled. See [Image Pull Secrets](./image-pull-secrets.md).

**Default:** not set

### `OBOT_SERVER_MCPSECRET_BINDING_ALLOWED_LABEL` {#obot_server_mcpsecret_binding_allowed_label}

Kubernetes Secret label key required before a Secret can be selected or resolved by MCP secret bindings. Only label presence is checked; the label value is ignored. Secrets without this label are not shown as bindable targets in the admin UI and are treated as unavailable when Obot resolves a secret binding at runtime.

**Default:** `obot.obot.ai/allow-secret-binding`

### `OBOT_SERVER_MCPCLUSTER_DOMAIN` {#obot_server_mcpcluster_domain}

The cluster domain to use for MCP services. Only matters if `OBOT_SERVER_MCPBASE_IMAGE` is set.

**Default:** `cluster.local`

### `OBOT_SERVER_SERVICE_NAME` {#obot_server_service_name}

The Kubernetes service name for the obot server. Automatically set by the helm chart when using kubernetes backend. Used to construct the internal service FQDN for MCP runtime callbacks.

**Default:** not set

### `OBOT_SERVER_SERVICE_NAMESPACE` {#obot_server_service_namespace}

The Kubernetes namespace where the obot server runs. Automatically set by the helm chart when using kubernetes backend. Used to construct the internal service FQDN for MCP runtime callbacks.

**Default:** not set

### `OBOT_SERVER_SINGLE_USER_IDLE_SERVER_SHUTDOWN_HOURS` {#obot_server_single_user_idle_server_shutdown_hours}

The interval in hours to check for idle single-user MCP servers and shut them down. Set to `-1` to disable idle shutdown.

**Default:** `24` (1 day)

### `OBOT_SERVER_MULTI_USER_IDLE_SERVER_SHUTDOWN_HOURS` {#obot_server_multi_user_idle_server_shutdown_hours}

The interval in hours to check for idle multi-user MCP servers and shut them down. Set to `-1` to disable idle shutdown.

**Default:** `168` (7 days)

### `OBOT_SERVER_DEFAULT_MCPCATALOG_PATH` {#obot_server_default_mcpcatalog_path}

The path to the default MCP catalog (accessible to all users).

**Default:** not set

### `OBOT_SERVER_DEFAULT_SYSTEM_MCPCATALOG_PATH` {#obot_server_default_system_mcpcatalog_path}

The path to the default System MCP catalog.

**Default:** not set

## MCP server network access {#mcp-server-network-access}

### `OBOT_SERVER_DISALLOW_LOCALHOST_MCP` {#obot_server_disallow_localhost_mcp}

Disallow MCP servers that try to connect to localhost. Set to `false` only when you intentionally need MCP servers to reach localhost from the Obot runtime environment.

**Default:** `true`

### `OBOT_SERVER_DISALLOW_PRIVATE_IPMCP` {#obot_server_disallow_private_ipmcp}

Disallow MCP servers that resolve to private IP addresses. Set to `false` only when you intentionally need MCP servers to reach private network services from the Obot runtime environment.

**Default:** `true`

### `OBOT_SERVER_DISALLOW_LINK_LOCAL_MCP` {#obot_server_disallow_link_local_mcp}

Disallow MCP servers that resolve to link-local addresses. Set to `false` only when you intentionally need MCP servers to reach link-local services from the Obot runtime environment.

**Default:** `true`

### `OBOT_SERVER_MCPNETWORK_POLICY_PROVIDER_CHART_REPO` {#obot_server_mcpnetwork_policy_provider_chart_repo}

Helm repository URL for the MCP server egress control provider chart. Used with `OBOT_SERVER_MCPNETWORK_POLICY_PROVIDER_CHART_NAME`.

**Default:** not set

### `OBOT_SERVER_MCPNETWORK_POLICY_PROVIDER_CHART_NAME` {#obot_server_mcpnetwork_policy_provider_chart_name}

Helm chart name for the MCP server egress control provider. Setting this enables MCP server egress control.

**Default:** not set

### `OBOT_SERVER_MCPNETWORK_POLICY_PROVIDER_CHART_VERSION` {#obot_server_mcpnetwork_policy_provider_chart_version}

Helm chart version for the MCP server egress control provider.

**Default:** not set

### `OBOT_SERVER_MCPNETWORK_POLICY_PROVIDER_CHART_PATH` {#obot_server_mcpnetwork_policy_provider_chart_path}

Local filesystem path to an MCP server egress control provider chart. Setting this enables MCP server egress control and cannot be combined with chart repo, name, or version.

**Default:** not set

### `OBOT_SERVER_MCPNETWORK_POLICY_PROVIDER_VALUES` {#obot_server_mcpnetwork_policy_provider_values}

YAML or JSON values blob merged into the MCP server egress control provider chart values.

**Default:** not set

### `OBOT_SERVER_MCPDEFAULT_DENY_ALL_EGRESS` {#obot_server_mcpdefault_deny_all_egress}

Default new MCP servers to deny all egress when MCP server egress control is enabled and no egress domains are configured.

**Default:** `false`

## MCP OAuth {#mcp-oauth}

### `OBOT_SERVER_MCPOAUTH_CLIENT_EXPIRATION` {#obot_server_mcpoauth_client_expiration}

The expiration time for dynamically registered MCP OAuth clients. Must be a valid duration string and may include days, hours, or minutes.

**Default:** `30d`

### `OBOT_SERVER_MCPOAUTH_CLIENT_NATIVE_EXCEPTIONS` {#obot_server_mcpoauth_client_native_exceptions}

A comma-separated list of additional Client ID Metadata Document URLs that default to the native application type when `application_type` is omitted.

**Default:** not set

### `OBOT_SERVER_FORCE_DYNAMIC_CLIENT` {#obot_server_force_dynamic_client}

Force Dynamic Client Registration when Obot authenticates to remote MCP servers, even when the authorization server supports Client ID Metadata Documents.

**Default:** `false`

## Device management {#devices}

### `OBOT_SERVER_MDM_ASSET_SOURCE` {#obot_server_mdm_asset_source}

The source for MDM assets. Can be a local directory, a tar archive path, or an HTTP(S) tarball URL.

## Skills {#skills}

### `OBOT_DEFAULT_SKILL_REPO_URL` {#obot_default_skill_repo_url}

The default skill repository URL. Must be a full HTTPS GitHub URL (e.g. `https://github.com/org/repo`). Only used on first-time setup (before the first owner user is created). A SkillRepository resource will be created from this URL and synced automatically.

**Default:** `https://github.com/obot-platform/skills`

### `OBOT_DEFAULT_SKILL_REPO_REF` {#obot_default_skill_repo_ref}

The ref (branch, tag, or commit SHA) for the default skill repository. If empty, the repository's default branch is used. Only used on first-time setup.

**Default:** not set
